# Manual de uso inicial

Nesta entrega existe somente a entrada da conta administradora e um painel de confirmação de sessão. As áreas de pacientes, medicamentos e estoque ainda não estão disponíveis.

Para preparar o ambiente, siga o README e o guia de configuração. Consulte as páginas oficiais atuais do Supabase e da Vercel para as interfaces e configurações externas; nomes de menus podem mudar. Não use informações reais de pacientes até comprovar o isolamento de acesso no banco.

A ferramenta é organizacional e não substitui um profissional de saúde.
